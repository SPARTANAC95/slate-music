# Slate Music 1.0.0

A native Windows player for your own music, with a dark Slate-inspired interface, artwork, fast search and a persistent listening session.

**Download `Slate Music_1.0.0_x64-setup.exe` below.** Windows 10/11 x64 and WebView2 are required. Installation is per user. Music files remain untouched.

Includes local library scanning and watching; songs, albums, artists, favorites and recently played; playlist editing; an editable queue; native gapless playback and optional crossfade; mini-player and Windows media controls; SQLite persistence; and Spotify album metadata matching against local files.

Updates check and download automatically by default. Update artifacts and their version are signature-verified, and installation requires confirmation or your choice on exit. Settings can disable checks and downloads. The installer itself does not have a Windows Authenticode publisher certificate, so Windows may show an unknown-publisher warning.

Validation includes unit tests, real-library decoding and seeking, native playback with Windows audio-output measurements, exact FLAC sample continuity, interface interaction tests and restart recovery. See the repository's `docs/VALIDATION.md` for exact coverage and remaining limits.

Spotify import requires your own Spotify Developer Client ID and account authorization; current Development Mode rules require an active Premium subscription for the app owner. It retrieves metadata only. No Spotify music is downloaded. Live sign-in, ordered album retrieval, local matching and manual correction were verified with an authorized developer app.

Audio output is 48 kHz stereo through the Windows default device. Opus, WMA, APE and protected files are unsupported. Existing library metadata and music never leave your machine as part of an update.
