# Slate Music 1.0.1

Download **Slate-Music_1.0.1_x64-setup.exe** for Windows 10/11 x64.

Fixes the updater download filename: release assets now use stable hyphenated names that GitHub preserves. The installer and update manifest are cryptographically signed and version-checked. This release retains your library, playlists, favorites, Spotify connection and paused listening session.

Includes the complete offline player introduced in 1.0.0, with native gapless audio, crossfade, mini-player, Windows media controls, read-only local-library indexing and Spotify album metadata matching. Real Spotify sign-in, album retrieval, matching, manual correction and ordered playback have been verified.

GitHub Actions is configured with an encrypted signing secret, but the account's billing lock prevented its jobs from starting. This release was built, tested and signed locally from the tagged source. See `docs/VALIDATION.md` for detailed verification and limits.

The update signature is separate from Windows Authenticode. No Authenticode publisher certificate is configured, so Windows may show an unknown-publisher warning. Output uses the Windows default device at 48 kHz stereo; Opus, WMA, APE and protected formats are unsupported.
