# Slate Music 1.0.1

Download **Slate-Music_1.0.1_x64-setup.exe** for Windows 10/11 x64.

Fixes the updater download filename: release assets now use stable hyphenated names that GitHub preserves. The installer is cryptographically signed and its update version is verified. This release retains your library, playlists, favorites, Spotify connection and paused listening session.

Includes the complete offline player introduced in 1.0.0, with native gapless audio, crossfade, mini-player, Windows media controls, read-only local-library indexing and Spotify album metadata matching. Real Spotify sign-in, album retrieval, matching, manual correction and ordered playback have been verified.

The initial GitHub billing block is resolved. [Windows CI](https://github.com/SPARTANAC95/slate-music/actions/runs/36187070441) and [hosted installer/signing verification](https://github.com/SPARTANAC95/slate-music/actions/runs/36187070416) both passed. The hosted build used the exact tagged source and the encrypted Actions signing secret; its downloaded artifact passed independent signature, checksum and tamper checks. The published installer remains the original build tested locally. See [the validation report](https://github.com/SPARTANAC95/slate-music/blob/main/docs/VALIDATION.md) for detailed verification and limits.

The update signature is separate from Windows Authenticode. No Authenticode publisher certificate is configured, so Windows may show an unknown-publisher warning. Output uses the Windows default device at 48 kHz stereo; Opus, WMA, APE and protected formats are unsupported.
