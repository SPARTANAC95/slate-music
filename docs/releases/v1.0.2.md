# Slate Music 1.0.2

A reliability update for your listening queue, local library and automatic updates, with a new [Slate Music website](https://spartanac95.github.io/slate-music/).

Download **Slate-Music_1.0.2_x64-setup.exe** for Windows 10/11 x64. Existing installations can download the signed update from Settings. Installation requires confirmation while playback is paused. Your database, playlists, favorites and Spotify connection are retained.

## What improved

- **A more dependable queue.** Search stays inside the queue; play, reorder and remove actions keep the correct original positions. Repeated songs remain separate entries. Adding to an empty queue enables playback, and removing the restored current entry selects the right paused replacement.
- **Safer playback.** A failed replacement file leaves the current session intact. Skipping an unavailable file at the repeat boundary keeps the current cursor correct. Short following tracks cannot be consumed entirely by a long crossfade.
- **More reliable library updates.** Rescan requests arriving during indexing are retained. Changed-file lookup scales better with larger libraries.
- **Clearer Spotify matches.** Different remasters require review. Saved matches display as missing when the local file disappears, and recover when it returns without changing tags or discarding the confirmed match.
- **Working history sorting.** Recently played opens in listening order and supports the other sorting options.
- **Robust update handling.** Later checks preserve an already downloaded update. Checks, downloads and installs cannot overlap; failures remain retryable.
- **A polished GitHub presentation.** The new website and visual README use real app captures of a clearly labelled fictional demonstration library.

## Verification

19 TypeScript tests and 18 native Rust tests passed locally, including codec fixtures, all 615 files in the read-only test library, measured gapless FLAC and crossfade behavior. The final native application also passed the 14 main interface scenarios and 11 focused queue, history, missing-file and watcher scenarios. Restart recovery and Windows audio output were checked separately. See the [validation report](https://github.com/SPARTANAC95/slate-music/blob/main/docs/VALIDATION.md) for evidence and remaining limits.

Updater signatures are configured; a Windows Authenticode publisher certificate is not. Windows may therefore show an unknown-publisher warning. Audio uses the default Windows device at 48 kHz stereo. Opus, WMA, APE and protected files are unsupported.
