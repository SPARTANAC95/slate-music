# Slate Music 1.1.5

Hearts that can be taken back, smart playlists that say why they are empty, and new defaults.

Download **Slate-Music_1.1.5_x64-setup.exe** for Windows 10/11 x64. Existing installations can download the signed update from Settings. Installation requires confirmation while playback is paused. Your database, playlists, favorites and Spotify connection are retained.

## Fixes

- **Hearts can be taken back.** Removing a favorite, or many at once from the selection bar, now shows **Undo**. Removed hearts are also remembered for 30 days, and when three or more are gone the Favorites page offers **Restore them**. Before, picking every song on the Favorites page and pressing Unfavorite removed every heart at once with no way back. Hearts removed before this version were not recorded and cannot be restored.
- **An empty smart playlist says why.** It used to say "Ready for your first song. Add songs with the folder button…", as if it were an ordinary playlist. It now lists each rule with how many songs it matches by itself ("Favorite is yes: no songs · Last played not in the last 90 days: 825 songs"), and says so when you simply have no favorites yet. The rule editor shows the same count beside every rule, so the one keeping songs out stands out.
- **A rule still being typed no longer changes the whole list.** With "any", an empty text rule let every song in; with "all", an empty number kept every song out. A rule without a value is now left out until it has one.

## Changes

- **New defaults for a new library:** a 4-second crossfade between songs (albums played in order stay gapless) and loudness levelling off. Libraries that already exist keep the settings they have.

## Verification

85 TypeScript tests, 112 native Rust tests and 35 browser checks of the real components passed. A build of this version was run as a native Windows app on a new disposable profile with generated songs:

- **Defaults.** The new profile started with a 4-second crossfade, levelling off and smart crossfade on.
- **Hearts.** Every song was hearted, then every heart removed at once from the Favorites page: **Undo** brought all of them back, and with the message dismissed the Favorites page's **Restore them** did. Separately, hearts set through the interface survived the app being killed, restarted and rescanned.
- **Smart playlists.** The app's rule engine was run over a real library of 825 songs for every ready-made playlist: Most played, Never played, Songs from the 80s, Recently added and Lossless only each held exactly the songs a direct count gives, in the right order.
- **Everything else.** All 28 interface scenarios and the 6 native lyric checks passed with the new defaults.

GitHub Actions built, tested and signed this installer on Windows. See the [validation report](https://github.com/SPARTANAC95/slate-music/blob/main/docs/VALIDATION.md).

Updater signatures are configured; a Windows Authenticode publisher certificate is not, so Windows may show an unknown-publisher warning. WMA, APE, DSD and protected files are unsupported.
