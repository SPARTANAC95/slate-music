# Slate Music 1.1.4

Opus files play, a welcome on first launch, and word-by-word lyrics only where they are exact.

Download **Slate-Music_1.1.4_x64-setup.exe** for Windows 10/11 x64. Existing installations can download the signed update from Settings. Installation requires confirmation while playback is paused. Your database, playlists, favorites and Spotify connection are retained.

## What's new

- **Opus files play.** .opus files, and .ogg files that hold Opus, are scanned, played, sought, levelled and played gaplessly like any other song. They are decoded by libopus itself, translated to Rust. Opus files with more than two channels are not supported yet.
- **A welcome on first launch.** A new library opens on a welcome instead of a folder dialog: use your Windows Music folder with one click or choose another, and decide lyrics online, artist photos and the Discord status there. All of it stays in Settings.

## Changes

- **Word by word only where it is exact, unless you ask.** Lyrics that only time each line now light the line being sung as a whole; lyrics with their own word times still light word by word. Estimated word timing inside line-timed lines remains available: **Lyrics options → Word by word → On**. If you had already chosen a setting there, it is kept.
- **Spotify import moved out of the sidebar.** It needs a Spotify developer app of your own, which most listeners won't set up, so it no longer has a permanent button there. It is on the Playlists page (**Import from Spotify**) and in the command bar, as before.

## Verification

81 TypeScript tests, 111 native Rust tests and 33 browser checks of the real components passed. A build of this version was run as a native Windows app on disposable profiles with generated songs:

- **Opus.** Two pure-Rust decoders were compared with the reference decoder on five files from 16 to 256 kbit/s, covering speech, hybrid and music modes; the one chosen came out the same length and within 0.00002 of every sample (the other failed on one file and was audibly wrong on two). In the running app an Opus song was scanned with its tags and length, played, sought to 60 seconds and found there, repeated, and handed over to the next song at its end.
- **Welcome.** On a profile with no music folder the welcome appeared, no folder was added or asked for, the Windows Music folder was offered, and its switches saved.
- **Everything else.** All 28 interface scenarios and the 6 native lyric checks passed on a new profile.

GitHub Actions built, tested and signed this installer on Windows. See the [validation report](https://github.com/SPARTANAC95/slate-music/blob/main/docs/VALIDATION.md).

Updater signatures are configured; a Windows Authenticode publisher certificate is not, so Windows may show an unknown-publisher warning. WMA, APE, DSD and protected files are unsupported.
