# Slate Music 1.1.6

Studio mode: every song as the artist mastered it, like Filmmaker Mode on a TV.

Download **Slate-Music_1.1.6_x64-setup.exe** for Windows 10/11 x64. Existing installations can download the signed update from Settings. Installation requires confirmation while playback is paused. Your database, playlists, favorites and Spotify connection are retained.

## New

- **Studio mode.** One switch (**Studio** in the player bar, Settings → Playback, or the command bar) sets the equalizer, loudness levelling and crossfades aside, plays albums gaplessly, and brings them all back when you turn it off.
- **Mastering-grade rate conversion in Studio mode.** Most songs are 44.1 kHz and Windows' shared mode plays at 48 kHz. The converter used until now draws straight lines between samples: from 44.1 to 48 kHz it lowers 10 kHz by 1.5 dB, 16 kHz by 3.9 dB and 19.5 kHz by 6 dB, and adds distortion only 13 to 22 dB below the music at 10 to 16 kHz. Lowering a hi-res song's rate, it dropped samples, so an inaudible 30 kHz tone in a 96 kHz file came back at 18 kHz only 9 dB down. Studio mode uses a polyphase Kaiser-windowed sinc filter: within 0.001 dB to 20 kHz, everything else at least 145 dB down. It adds no delay, keeps every song's exact length, and carries on across songs that run into each other on an album, so they meet without a seam.
- **Peaks never clip in Studio mode.** Each song's true peak is now measured with its loudness (songs measured before are measured again in the background). When the volume would push a song's peaks past full scale, Studio mode holds it just below, for that song only. Songs sent at their own rate in exclusive mode stay bit-perfect at 100%.
- **Signal path** shows Studio mode, the conversion it uses and any volume it holds back.

## Verification

85 TypeScript tests, 127 native Rust tests and 35 browser checks of the real components passed. The converter was measured against the old one on test tones and on real albums: a song that runs into the next converts bit-identically to the two converted as one recording, at 0.7% of one CPU core for 44.1 kHz and 2.6% for 192 kHz. A release build was run as a native app on a disposable profile with generated 44.1 and 96 kHz songs, silently: Studio mode switched on and off from the engine and the player bar, album songs ran into each other without a crossfade, the hi-res song converted, played and sought, and Signal path and Settings showed the mode.

GitHub Actions built, tested and signed this installer on Windows. See the [validation report](https://github.com/SPARTANAC95/slate-music/blob/main/docs/VALIDATION.md).

Updater signatures are configured; a Windows Authenticode publisher certificate is not, so Windows may show an unknown-publisher warning. WMA, APE, DSD and protected files are unsupported.
