# Slate Music 1.1.3

Fixes the question mark in place of the cover on Discord, and makes word-by-word lyrics glide.

Download **Slate-Music_1.1.3_x64-setup.exe** for Windows 10/11 x64. Existing installations can download the signed update from Settings. Installation requires confirmation while playback is paused. Your database, playlists, favorites and Spotify connection are retained.

## Fixes

- **A question mark instead of the cover on Discord.** 1.1.2 took covers from the Cover Art Archive, whose pictures do not always load, and Discord shows a question mark for a picture it cannot fetch. Covers now come from Apple's iTunes catalogue first, then Deezer's, then the Cover Art Archive, and one is used only after its picture has actually loaded. Albums looked up by 1.1.2 are looked up again. Editions are recognised too ("Bad 25th Anniversary" finds the cover of "Bad").
- **Word-by-word lyrics looked rough.** Each word used to fill by itself, so the soft edge of the light shrank and grew at every word, its speed stepped from word to word, and the letters shifted slightly as they lit. The line being sung is now lit by one light that travels through it: the edge keeps its width across the gaps between words and from one row of a wrapped line to the next, its speed changes gently, and the letters stay still.

## Changes

- **Lyrics are found online without switching anything on.** **Find lyrics online** is now on unless you switch it off, and this update switches it on once for everyone already using Slate Music: songs without lyrics of their own are looked up on LRCLIB when you open Now Playing (the artist, title, album and length are sent). Settings → Library switches it off, and it then stays off.
- **To show covers on Discord**, the album and artist name are now sent to Apple's iTunes Search and, if needed, Deezer and MusicBrainz, instead of MusicBrainz alone. **Show the album cover** in Settings → Discord status switches the lookup off.
- **Last.fm is ready to work with nothing to set up.** A release built with Slate Music's own Last.fm API account needs only **Connect Last.fm** and your approval in the browser. Where a build does not carry that account, Settings asks for an API account of your own as before, and **Use my own API account** remains either way.

## Verification

81 TypeScript tests, 109 native Rust tests and 32 browser checks of the real components passed. A build of this version was run as a native Windows app on disposable profiles with generated silent songs: all 28 interface scenarios and the 6 native lyric checks passed on a new profile.

- **Discord, in a real Discord client.** The same status was sent to a running Discord with three pictures and Discord's own image service was asked for each: the iTunes cover and the Slate Music icon were served (200), and the Cover Art Archive address 1.1.2 used was not (502), which is the question mark.
- **Discord, from the app.** Followed against a stand-in for Discord on a profile left by 1.1.2: the address saved by 1.1.2 was not reused, the album was looked up again and its new cover loaded; an album in no catalogue showed the icon; pausing cleared the status.
- **Lyric animation.** Sampled every frame for 20 seconds in the native app at 144 frames a second: every frame arrived on time (worst 7.2 ms), and the light never stepped back or jumped. A browser check now follows the light frame by frame.
- **The lyrics default.** A new profile started with Find lyrics online on; the 1.1.2 profile had it switched on by the update with its other settings untouched; switched off afterwards, it was still off after a restart.

GitHub Actions built, tested and signed this installer on Windows. See the [validation report](https://github.com/SPARTANAC95/slate-music/blob/main/docs/VALIDATION.md).

Word times inside line-timed lyrics remain an estimate; only lyrics with their own word times (Enhanced LRC) are exact. Updater signatures are configured; a Windows Authenticode publisher certificate is not, so Windows may show an unknown-publisher warning. Opus, WMA, APE and protected files are unsupported.
